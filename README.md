# 🎧 Spotify AI Playlist Maker

Веб-приложение на Python и Streamlit: опишите музыку на русском, английском или французском, найдите реальные композиции в Spotify, отредактируйте подборку и подтвердите создание **приватного** плейлиста.

Приложение предназначено для **локального запуска на вашем компьютере**, одним пользователем. Оно не опубликовано. Инструкции ниже не публикуют проект и не отправляют код в GitHub.

## Что уже работает

- Интерфейс без ключей: описание, целевое время и демо-поисковые предложения.
- Spotify OAuth 2.0 Authorization Code + PKCE (S256), случайный `state`, проверка cookie, одноразовый callback и обновление токена. Client Secret не нужен.
- Свободный интеллектуальный подбор через OpenAI; модель возвращает только запросы с исполнителями и названиями, **не Spotify ID**.
- Поиск и длительность из Spotify Web API, фильтрация недоступных результатов.
- Удаление, замена, добавление и изменение порядка; защита от повторов по ID и названию/исполнителю, включая некоторые переиздания.
- Подбор целых треков в рамках времени. Приложение старается заполнить время, но не обещает точного совпадения: каталог конечен, песни нельзя обрезать.
- Создание приватного плейлиста после отдельного подтверждения. Перед созданием треки проверяются повторно; после заполнения проверяются приватность и порядок.
- Таймауты, ограниченное ожидание `429 Retry-After`, обновление входа при `401`, объяснение `403`, запрет автоматического повторного создания при неизвестном результате записи.
- Автоматические тесты логики, PKCE, API-клиента и интерфейса.

**Без Spotify ничего не выдаётся за найденный трек.** Демо показывает только запросы, без ID и длительности. Для поиска реальных треков нужен Spotify, даже если OpenAI отключён. Демо содержит по шесть предложений в нескольких категориях, распознаёт лишь некоторые слова и не понимает произвольные эпохи и настроения. Для полного подбора используйте OpenAI. Результаты ИИ и поиска всегда проверяйте перед сохранением: совпадение жанра, эпохи и настроения не гарантируется.

## 1. Установите Python и откройте папку

1. Установите Python **3.12** с [python.org](https://www.python.org/downloads/). В Windows при установке отметьте **Add Python to PATH**.
2. Откройте https://github.com/egoconsultation-code/DJ-Psycho, нажмите **Code → Download ZIP** и полностью распакуйте архив на компьютер. Не переносите папку `.venv`: её нужно создать заново.
3. Откройте терминал в папке `DJ-Psycho`, где лежит `app.py`. В Windows можно щёлкнуть адресную строку Проводника, ввести `powershell` и нажать Enter. В macOS откройте Terminal и перейдите в папку командой `cd`.

Дальше копируйте команды **по одной строке**. Обозначения `PS>` или `$` вводить не нужно.

### Windows (PowerShell)

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

`Copy-Item` выполняйте только если `.env` ещё нет — не перезаписывайте свои настройки.

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
cp -n .env.example .env
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

Если браузер не открылся сам, введите в адресной строке `http://127.0.0.1:8501`. Это адрес приложения на вашем компьютере. Остановить его можно сочетанием **Ctrl+C** в терминале. Чтобы снова запустить, достаточно последней команды; переустанавливать зависимости каждый раз не нужно.

Для обновления зависимостей разработчиком используется `requirements-dev.txt`. `requirements.lock.txt` фиксирует версии, установленные и протестированные в Python 3.12/Linux; на другой ОС pip может выбрать соответствующие колёса тех же версий. Если для вашей ОС нет подходящего пакета, не отключайте проверки TLS — сообщите текст ошибки без секретов.

## 2. Попробуйте демо без ключей

1. Оставьте «Демо-подбор без OpenAI» включённым.
2. Введите, например: «Спокойный джаз для вечера».
3. Выберите время и нажмите **«Подобрать музыку»**.
4. Вы увидите поисковые предложения. Пока Spotify не подключён, список реальных треков остаётся пустым, а создание плейлиста недоступно.

## 3. Создайте приложение в Spotify

Для этого нужен ваш аккаунт Spotify и доступ к [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).

1. Войдите в Dashboard и создайте приложение (**Create app**), если эта возможность доступна вашему аккаунту.
2. Назовите его, например, `My Playlist Maker`, заполните обязательное описание и выберите **Web API**, если предлагается выбор API.
3. В **Redirect URIs** добавьте **точно**:

   ```text
   http://127.0.0.1:8888/callback
   ```

   Нужен именно `127.0.0.1`, порт `8888` и путь `/callback`, без завершающего `/`. `localhost` и порт интерфейса `8501` не заменяют этот адрес. Loopback HTTP используется для локального PKCE; для обычных внешних адресов Spotify требует HTTPS.
4. Сохраните настройки.
5. Если Dashboard показывает **User Management / Users and Access**, убедитесь, что ваш Spotify-аккаунт добавлен в разрешённые пользователи приложения (обычно нужен адрес электронной почты Spotify). Используйте тот же аккаунт при входе.
6. Скопируйте **Client ID**. Это публичный идентификатор приложения. **Client Secret не копируйте и не добавляйте** — PKCE его не использует.
7. Откройте файл `.env` в обычном текстовом редакторе. Вставьте Client ID справа от `=`:

   ```dotenv
   SPOTIFY_CLIENT_ID=ваш_client_id
   SPOTIFY_REDIRECT_URI=http://127.0.0.1:8888/callback
   OPENAI_API_KEY=
   OPENAI_MODEL=gpt-4.1-mini
   ```

8. Сохраните файл, остановите Streamlit (**Ctrl+C**) и запустите снова последней командой из шага 1.
9. Слева нажмите **«Подготовить вход Spotify»**, затем **«Войти в Spotify»**. Ссылка откроется в новой вкладке. Не закрывайте исходную вкладку приложения.
10. Разрешите доступ к приватным плейлистам. Приложение запрашивает `playlist-modify-private` и `playlist-read-private`, без права создавать публичные плейлисты.
11. После возврата на страницу callback вернитесь в исходную вкладку и нажмите **«Проверить вход»**. Должна появиться надпись «Spotify подключён».

**Важно для облачной среды:** адрес `127.0.0.1` в вашем браузере указывает на ваш компьютер, а не на удалённую машину. OAuth этой версии проверяйте при локальном запуске. Не используйте случайный туннель и не меняйте адрес на публичный без отдельной настройки и проверки безопасности. Облачная публикация — отдельный этап только с вашего согласия.

### Spotify Development Mode и изменения 2026 года

Spotify меняет доступность API независимо от кода. Для новых приложений действуют ограничения Development Mode: ориентируйтесь на требование **Premium у владельца приложения**, небольшой список разрешённых пользователей (в правилах 2026 года — до **5**) и ограничения числа приложений (для новых разработчиков — обычно **1 Client ID**). У ранее созданных приложений и Extended Quota Mode условия могут отличаться. Добавление пользователей не заменяет Premium и не выдаёт расширенную квоту. Фактические права показывает ваш Dashboard.

Код ориентирован на семейство API 2026 года:

- поиск `GET /v1/search`, `type=track`, `limit=10`;
- профиль `GET /v1/me` и отдельная проверка `GET /v1/tracks/{id}`;
- создание `POST /v1/me/playlists` с `public=false`;
- заполнение `PUT /v1/playlists/{id}/items` (полная замена, до 100 треков);
- проверка `GET /v1/playlists/{id}`;
- не используются Recommendations, Audio Features, Audio Analysis, массовое получение треков, популярность или списки доступных рынков, на доступность которых нельзя полагаться в Development Mode.

**Ограничение проверки актуальности:** во время разработки 31 октября 2026 года официальный сайт `developer.spotify.com` вернул блокировку сетевого прокси среды (403). Поэтому перечисленные условия и современные endpoints нельзя считать сверенными с живой документацией на эту дату. API-логика проверена автоматическими тестами с моделируемыми ответами, **реальный OAuth и операции вашего аккаунта ещё не проверены**. Необработанные изменения Spotify могут потребовать корректировки клиента; старые endpoints не вызываются автоматически, чтобы не создать второй плейлист.

Перед реальным подключением сверьте в Dashboard и официальной документации:

- [Development Mode](https://developer.spotify.com/documentation/web-api/concepts/development-mode)
- [Миграция API 2026](https://developer.spotify.com/documentation/web-api/references/2026-migration-guide)
- [PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow)
- [Redirect URI](https://developer.spotify.com/documentation/web-api/concepts/redirect_uri)
- [Search](https://developer.spotify.com/documentation/web-api/reference/search)
- [Create Playlist](https://developer.spotify.com/documentation/web-api/reference/create-playlist)
- [Rate Limits](https://developer.spotify.com/documentation/web-api/concepts/rate-limits)

Если конкретная страница перемещена, найдите её по названию через раздел Web API на сайте Spotify. При ошибке `403` сначала проверьте Premium владельца, allowlist пользователя и разрешения; при `404/405` — актуальные endpoints. Не пытайтесь обходить ограничения Development Mode.

## 4. Подключите OpenAI (необязательно)

1. Создайте API-ключ в [OpenAI Platform](https://platform.openai.com/api-keys). API оплачивается отдельно от подписки ChatGPT.
2. Задайте небольшой бюджет и проверьте billing в OpenAI Platform.
3. Добавьте ключ **только в локальный `.env`** справа от `OPENAI_API_KEY=`. Не отправляйте ключ в чат, описание музыки или GitHub.
4. `OPENAI_MODEL=gpt-4.1-mini` — начальный вариант. При отсутствии доступа укажите модель вашего аккаунта с поддержкой Chat Completions и JSON mode.
5. Перезапустите приложение и выключите «Демо-подбор без OpenAI».

OpenAI получает ваше описание и длительность. Ответы Spotify, ваша библиотека, имя аккаунта и токены в OpenAI не отправляются. Даже если модель предложит несуществующее название, оно не попадёт в плейлист без результата поиска Spotify. Совпадение названия не гарантирует правильную версию записи — прослушайте результат.

## 5. Соберите и сохраните плейлист

1. Опишите жанр, годы, настроение и язык; время задайте отдельным полем. Например: `French electronic music, 1995–2010, relaxed and warm, no live recordings`.
2. Нажмите **«Подобрать музыку»**, затем **«Найти реальные треки в Spotify»**.
3. Проверьте названия, исполнителей и длительность. Нажмите ссылку трека для прослушивания в Spotify.
4. `↑` и `↓` меняют порядок, `✕` удаляет трек, `↻` открывает замену. В разделе добавления можно найти другую композицию вручную.
5. Повторы по умолчанию запрещены. Если они нужны, включите соответствующий флажок перед подбором. Обнаружение разных версий не идеально: проверьте каверы и ремиксы вручную.
6. Проверьте общую длительность. Дополнительный трек, превышающий время, не добавится. Для нового целевого времени создайте подборку заново.
7. Укажите название и описание плейлиста. Отметьте **«Подтверждаю создание…»** и нажмите **«Создать приватный плейлист»**.
8. Нажмите **«Открыть готовый плейлист в Spotify»** после подтверждения результата.

Если добавление треков оборвалось, пустой или частично заполненный **приватный** плейлист может уже существовать. Кнопка повтора заполняет **тот же** плейлист целиком, не создавая новый. Не редактируйте его одновременно в Spotify: повтор заменяет содержимое утверждённым списком. Если ответ на само создание потерялся, автоматического повтора нет — сначала проверьте аккаунт вручную.

## Частые затруднения

| Что происходит | Что сделать |
| --- | --- |
| `INVALID_CLIENT` | Проверьте Client ID в `.env`; Client Secret не нужен. Перезапустите приложение. |
| `INVALID_REDIRECT_URI` | В Dashboard и `.env` должен быть точно `http://127.0.0.1:8888/callback`. |
| Порт 8888 занят | Закройте вторую копию приложения или процесс, использующий порт. |
| Вход истёк / проверка безопасности не пройдена | Начните вход заново, разрешите cookie для `127.0.0.1`, завершите за 10 минут. Используйте один браузер и исходную вкладку. |
| Вход после перезапуска потерян | Это ожидаемо: токены хранятся только в оперативной памяти. Войдите снова. |
| `401` | Обновление токена выполняется автоматически; если не помогло, выйдите и войдите снова. |
| `403` | Проверьте условия Development Mode и доступ пользователя в Dashboard. |
| `429` | Подождите указанное время. Приложение делает не больше 3 попыток и не ждёт длинный лимит автоматически. |
| Результатов мало | Измените описание, увеличьте время, подключите OpenAI или добавьте композиции вручную. Каталог зависит от страны аккаунта. |
| OpenAI недоступен | Проверьте billing, модель и ключ. Включите демо — Spotify-поиск продолжит работать. |
| Сетевая ошибка | Проверьте интернет и разрешения прокси. Не отключайте TLS/сертификаты. |

Для облачной сети нужны HTTPS-домены `accounts.spotify.com`, `api.spotify.com`, `api.openai.com` (если используется ИИ), `developer.spotify.com` (документация), а для установки — `pypi.org` и `files.pythonhosted.org`. Блокировки политики меняются в настройках среды, а не в коде приложения. Ключ OpenAI должен быть настоящим локальным значением для локального запуска; прокси-подстановки облачной платформы не переносите в `.env`.

## Тесты для разработчика

macOS / Linux:

```bash
.venv/bin/python -m pytest -q
```

Windows:

```powershell
.venv\Scripts\python.exe -m pytest -q
```

Тесты не обращаются к аккаунтам Spotify и OpenAI, не требуют ключей, не создают плейлисты и не расходуют API-бюджет. UI-тесты используют Streamlit AppTest. Тестовая конфигурация отключает чтение `.env` и убирает ключи из окружения на время каждого теста.

## Структура

```text
app.py                     — интерфейс Streamlit
playlist_maker/auth.py     — локальный callback и PKCE
playlist_maker/spotify.py  — Spotify API, лимиты и ошибки
playlist_maker/planner.py  — OpenAI и демо-планировщик
playlist_maker/models.py   — треки, повторы и длительность
tests/                     — автоматические тесты
.env.example               — шаблон настроек без секретов
requirements.lock.txt      — проверенные версии зависимостей
```

`.env`, `.venv`, токены, логи и кэши исключены через `.gitignore`. Токены Spotify живут только в памяти и теряются при перезапуске; выход из приложения убирает их из текущей сессии. Чтобы полностью отозвать разрешение, удалите доступ приложения в настройках Spotify. Код рассчитан на персональный локальный запуск, не является готовым многопользовательским облачным сервисом. Не публикуйте его без отдельного согласования настройки HTTPS, callback, хранения секретов и ограничений доступа.
