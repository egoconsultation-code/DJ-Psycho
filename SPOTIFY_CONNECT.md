# Подключение DJ Psycho к Spotify

В GitHub находится только шаблон `.env.example`, без ключей и токенов. Client Secret не используется. Ваш Client ID нужно один раз указать локально в `.env`.

## На вашем компьютере

1. Откройте https://github.com/egoconsultation-code/DJ-Psycho и нажмите **Code → Download ZIP**. Полностью распакуйте архив в отдельную папку. Не запускайте файлы прямо внутри ZIP. В Проводнике включите **Вид → Показать → Расширения имён файлов**. Скопируйте `.env.example` в той же папке и назовите копию точно `.env` (не `.env.txt`). Откройте `.env` в Блокноте и вставьте свой Spotify Client ID после `SPOTIFY_CLIENT_ID=`. Сохраните файл. Redirect URI уже указан; Client Secret не добавляйте.
2. Если Python ещё не установлен, установите **Python 3.12** с https://www.python.org/downloads/ . В Windows отметьте **Add Python to PATH**.
3. В Windows дважды щёлкните `Запустить Windows.bat`. В macOS запустите `Запустить macOS.command`. Первый запуск установит библиотеки; оставьте окно терминала открытым.
   - Если macOS не разрешает запуск файла или ZIP потерял право исполнения, откройте Terminal, введите `bash ` (с пробелом), перетащите файл `.command` в окно Terminal и нажмите Enter. Не отключайте системные средства защиты.
4. Если браузер не открылся сам, введите в адресной строке **http://127.0.0.1:8501**.
5. Слева нажмите **«Подготовить вход Spotify»**, затем **«Войти в Spotify»**. Откроется вкладка Spotify. Не закрывайте исходную вкладку приложения.
6. Войдите в Spotify аккаунтом, разрешённым для приложения DJ Psycho в Developer Dashboard, и подтвердите доступ к приватным плейлистам.
7. После возврата на страницу с сообщением о завершении входа вернитесь в исходную вкладку приложения и нажмите **«Проверить вход»**. Ожидается надпись **«Spotify подключён»**.
8. Оставьте включённым **«Демо-подбор без OpenAI»**, введите «джаз для вечера», нажмите **«Подобрать музыку»**, затем **«Найти реальные треки в Spotify»**. Появление реальных названий, исполнителей и длительности подтверждает доступ к Spotify Web API.

Для проверки входа **не нужно создавать плейлист**. Без вашего отдельного подтверждения приложение ничего не создаёт в Spotify.

## Если вход не работает

- В Spotify Developer Dashboard должен быть сохранён ровно `http://127.0.0.1:8888/callback`, без завершающего `/`.
- Проверьте, что используемый аккаунт добавлен в разрешённые пользователи приложения, если этого требует Development Mode. Проверьте также актуальные требования Premium в Dashboard.
- Если порт 8888 занят, закройте другие копии приложения. Если проверка входа истекла, начните вход заново и завершите за 10 минут.
- Если окно callback не открывается, убедитесь, что приложение запущено **на том же компьютере**, где открыт браузер. Запуск в облаке с этим loopback-адресом не завершит вход на вашем компьютере.
- При ошибке сообщите только текст ошибки. **Не отправляйте адрес callback из браузера, `code`, токены, cookie или содержимое `.env`.**
